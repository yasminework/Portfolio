Rora Orchards — Sales Analysis Dashboard

End-to-end sales and payment visibility across consignment and bin-based fruit and blueberry sales channels.

SQL ServerPower AutomateSharePointPower BI
Details

Data architecture: Sales data sourced from an on-premises SQL Server database via an On-Premises Data Gateway. Payment files arrive by email, triggering a Power Automate flow that extracts attachments and saves them to SharePoint. Power BI consolidates both sources into one reporting layer.

  • Consignment Dashboard — STD Cartons Sold, Total Payment, KG Sold, R/Carton, R/KG, paid vs not-paid breakdowns, seasonal trends.
  • Bins Dashboard — #Bins Sold, Total Payment, Tons Sold, R/Bin, R/Ton, segmented by agent, farm, commodity, variety, packing method.
  • Sales Detail Table — drill-through view with dynamic dimension and measure selectors.
  • Future Payments Analysis — outstanding payments by commodity, agent, week/month/year.

Rora Orchards — Berries Picking Dashboard

Operational visibility into the blueberry picking season — productivity, quality, wages, and weather correlation.

SQL ServerSharePointWeather APIPower BI
Details

Data architecture: Picking data from on-premises SQL Server via gateway; budget data from Excel/SharePoint; live weather data via external API for quality correlation analysis.

  • Picking Analysis — Hectares Planted, Picking KG & Wages (Actual vs Budget), Picking R/KG, variance indicators by grade and variety.
  • Picking vs Consignment Analysis — bridges operational and commercial data with weekly/monthly trends.
  • Picking Wages Analysis — auto-generated narrative highlights: peak wage weeks, top hours, average R/Hour.
  • Sizeband Analysis — berry size distribution across six size bands with Durafel scoring.
  • Durafel & Weather Analysis — firmness and weight correlated against live temperature and rainfall data.
